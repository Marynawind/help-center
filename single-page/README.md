# One-file builds

Generated by `python3 build-bigcommerce.py`. Do not edit these by hand — edit
`index.html`, `styles.css`, `app.js` in the project root and rebuild.

| File | Size | Use it when |
|---|---|---|
| `help-center-embed.html` | ~175 KB | **The one for BigCommerce.** Pasted into a Web Page in the store admin |
| `help-button-script-manager.html` | 3 KB | The floating Help button, for Script Manager. No theme access needed |
| `help-center-script-manager.html` | 13 KB | Only if the page editor strips the page's `<script>` |
| `help-center.html` | ~171 KB | A complete document. Open it anywhere, host it anywhere |

Both carry everything inside them: markup, styles, script, and the watermark as
a `data:` URI. The only outside request either makes is the Google Fonts call
for Barlow and Roboto Condensed.

## Putting the embed file into BigCommerce

1. **Storefront → Web Pages → Create a Web Page**
2. Page type **Web Page**, name it `Help Center`
3. In the content editor switch to **HTML / source view** — the icon is usually
   `< >` or **Tools → Source code**
4. Paste the whole of `help-center-embed.html`
5. Save

**Switch to source view before pasting, and avoid switching back.** A visual
editor rewrites what it does not understand: it will strip the `<style>` and
`<script>` blocks and the page will render as unstyled text. If that happens,
undo, re-open source view and paste again.

## If the editor strips the script anyway

Some BigCommerce plans sanitise `<script>` out of page content no matter what.
Two symptoms: the guide is permanently open, and the search does nothing.

In that case use the theme route instead — `bigcommerce/` in this repository has
the same page as a Stencil template, where the script lives in a real file and
cannot be stripped. `bigcommerce/INSTALL.md` has the steps.

## The Help button on every other page

There is no theme access, so it goes in as a script rather than a theme edit.

1. **Storefront → Script Manager → Create a Script**
2. Name `Help Center button`, Location **Footer**, Pages **All pages**,
   Script type **Script**, Method **Script tag**
3. Paste the whole of `help-button-script-manager.html`
4. Set `HELP_URL` at the top to the URL you gave the page

A tab on the right edge of the window that holds its place while the page
scrolls; on a phone a round button clear of the bottom-right corner. It hides
itself on the Help Center — by URL, and also by the page being there at all, so
a different URL still does the right thing.

`z-index: 900` puts it above page content and below a modal or cookie banner.
Lower it if it covers a chat widget.

## Making the paste smaller

The watermark is about 90 KB of the 175 KB, carried as a `data:` URI so the file
needs no uploads. To trim it:

1. Upload `bigcommerce/assets/img/help-center-watermark.png` through
   **Storefront → Image Manager**
2. Copy the URL it gives you
3. In the pasted block find `url("data:image/png;base64,` — it appears once —
   and replace the whole `url(...)` with `url("<that URL>")`

That brings the paste down to about 85 KB.

## Scoping

Every class in the embed file is prefixed `hc-` and every rule is scoped to
`.hc-root`, so the page and the store theme cannot affect each other. The
standalone file is unprefixed, because nothing else shares the document.
